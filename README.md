# 🌸 Task Garden

A customizable to-do list app where tasks are visualized 
as a flower garden built with Python and cmu_graphics.

## Features
- Add tasks with urgency levels and categories
- Watch sprouts bloom into flowers as you complete tasks
- Confetti animation when all tasks are complete
- Edit and delete tasks

## Requirements
- Python 3
- cmu_graphics library

## Installation

Install cmu_graphics:
pip install cmu-graphics

## How to Run
python task_garden.py

## How to Use
1. Click "Add Task" to create a new task
2. Enter task text, select urgency (1-3) and type
3. Check off tasks to watch them bloom into flowers!
4. Complete all tasks for a confetti celebration 🎉

## Task Types & Colors
- Academic → Blue flowers
- Personal → Purple flowers  
- Chores → Yellow flowers
- Miscellaneous → Pink flowers

## Limits
- Max 8 tasks total
- Max 5 tasks per category
